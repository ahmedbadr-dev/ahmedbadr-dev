## About

I'm a full-stack developer based in **Egypt**, focused on shipping real products:

- **Mobile apps** with React + Capacitor / Flutter (Android-first, production builds)
- **Modern web apps** with TypeScript, React, and clean UI systems
- **Cloud & auth** with Firebase (Auth, Firestore rules, secure client flows)
- **AI integrations** (Gemini) for assistants and in-app experiences
- **Hardware-adjacent features** such as NFC product unlocks and location-aware services

I care about polish, reliability, and clear architecture — the kind of work that holds up in production and interviews.
