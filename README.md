## About Me

I'm a full-stack and mobile engineer based in **Egypt**, focused on building practical software products and business applications.

- **Web Development:** Modern interfaces, dashboards, admin panels, and responsive web applications.
- **Mobile Development:** Flutter applications and React-based mobile apps using Capacitor.
- **Backend Engineering:** REST APIs, authentication, authorization, business logic, and third-party integrations.
- **Business Systems:** CRM and ERP platforms, real-estate workflows, and operational management tools.
- **Database & Security:** Relational databases, access controls, API security, and reliable data handling.
- **AI & Automation:** Gemini integrations, AI-assisted development, and application workflow automation.
- **Deployment & Delivery:** Production configuration, hosting, mobile release preparation, and troubleshooting.

My focus is on delivering complete, maintainable products rather than isolated features.
