## Featured Projects

### 01. [Elaf — Islamic Companion](https://github.com/ahmedbadr-dev/elaf-islamic-companion)

An Android-focused Islamic companion application built with React, Capacitor, and Firebase.

**Key features**
- Location-based prayer times and Qibla direction.
- NFC-based mistaha claiming and PRO access unlocking.
- Quran access and live streams.
- Gemini-powered AI assistant.
- Local notifications and prayer widget.

**Technologies:** React · Capacitor · Firebase · Google Gemini · NFC

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/ahmedbadr-dev/elaf-islamic-companion)

### 02. [Voice AI Assistant](https://github.com/ahmedbadr-dev/voice-ai-assistant)

A Python-based voice assistant connecting speech recognition, Gemini responses, and offline text-to-speech.

**Key features**
- Microphone input and speech-to-text processing.
- Gemini-powered conversational responses.
- Offline text-to-speech output.
- Arabic and English voice interaction.
- Environment-based API key configuration.

**Technologies:** Python · Google Gemini · Speech-to-Text · Text-to-Speech

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/ahmedbadr-dev/voice-ai-assistant)
